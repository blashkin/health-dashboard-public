Читаю архив

Как менялись шаги, тренировки, пульс покоя и сон за годы с часами.

И как это соотносится с рекомендациями ВОЗ. Архив читается в браузере и никуда не уходит.

Нужны только для норм VO₂max и сна, можно пропустить. Никуда не отправляются.

Как выгрузить с iPhone. «Здоровье» → фото профиля → «Экспортировать медданные». Получится zip. Через AirDrop на этот компьютер.
Если zip не открывается. Дождитесь конца экспорта на телефоне. Файл может занимать более 1 ГБ. Не распаковывайте вручную: нужен именно zip.
Почему это безопасно. Страница не отправляет файл на сервер: разбор идёт в браузере, на диск ничего не пишется. Закрыли вкладку — данных нет.
